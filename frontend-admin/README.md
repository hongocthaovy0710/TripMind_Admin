# Frontend Admin

Ứng dụng React + TypeScript + Vite dành riêng cho Admin.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Build production: `npm run build`. Cấu hình URL backend bằng `VITE_API_BASE_URL`. Chạy độc lập trên cổng 5173; backend mặc định là `http://localhost:8081`.
