# Tổng quan dự án

AI Travel Planner Admin Website là repository riêng cho đội ngũ quản trị. Phạm vi dự kiến gồm dashboard, quản lý người dùng và nội dung du lịch, theo dõi chuyến đi/hoạt động, cấu hình tích hợp. Hiện repository chỉ tạo nền tảng ứng dụng và dashboard rỗng; chưa triển khai nghiệp vụ hay dữ liệu mẫu.

Backend và frontend có thể chạy độc lập. Schema PostgreSQL, hợp đồng API và quyền truy cập dữ liệu cần được nhóm Admin/User thống nhất trước khi xây dựng module nghiệp vụ.
