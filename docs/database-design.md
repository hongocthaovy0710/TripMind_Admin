# Thiết kế dữ liệu

Chưa tạo thiết kế schema hoặc bảng. Đây là chủ ý để tránh xung đột với repository User và chờ nhóm thống nhất mô hình dữ liệu dùng chung.

Trước khi thêm entity/migration, cần thống nhất chủ sở hữu từng bảng, quy ước ID, quan hệ, trạng thái tài khoản/nội dung, lịch sử cập nhật và chiến lược migration giữa hai backend.
